# harvardx-data-analysis-week1
Practical implementation of Week 1 - HarvardX Data Analysis for Life Sciences course on edX. Covers R, RStudio, GitHub, dplyr, and Exploratory Data Analysis (EDA).

## What I Learned
- R & RStudio setup, packages (install.packages, library)
- GitHub workflow (finding and downloading course datasets)
- RStudio interface (Source, Console, Environment, Plots)
- dplyr basics: filter(), select(), unlist(), pipe (%>%)
- Exploratory Data Analysis: Histogram, QQ-plot, Boxplot
